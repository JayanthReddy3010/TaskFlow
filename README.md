🚀 TaskFlow – Smart Task Manager Web App

I have successfully designed and developed TaskFlow, a modern and responsive task management web application as part of my Web Development practice and portfolio projects.

TaskFlow helps users efficiently manage their daily tasks with a clean UI and smooth user experience.

✨ The application showcases:

👨‍💻 User authentication UI (Login & Register - Frontend)
📝 Add, view, and manage tasks
✅ Mark tasks as completed
🗑️ Delete tasks easily
📊 Real-time task statistics dashboard
🎨 Modern neon-dark UI design
📱 Fully responsive layout for all devices
💾 Local storage-based task persistence (frontend version)
